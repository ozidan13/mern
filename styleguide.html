Real-Life Analogy · تشبيه من الواقع

Information

State updates in React 19 are automatically batched across all asynchronous boundaries.

Warning · تحذير

Mutating state directly will bypass the reconciliation algorithm and break UI synchronization.

Common Pitfall · فخ شائع

Calling useState inside an if condition violates the Rules of Hooks.

Legacy Note · ملاحظة للأنظمة القديمة

In React 17 and earlier, promises and timeouts were not automatically batched.

  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(c => c + 1)}>
      Count: {count}
    </button>
  );
}
