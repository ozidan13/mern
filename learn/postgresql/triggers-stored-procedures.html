المشكلة الهندسية والسياق الواقعي · The Architectural Problem

رؤية الواقع العملي والنموذج الذهني · Real-World Context & Mental Model

في الأنظمة المالية والتطبيقات المحاسبية، الاعتماد على كود الباك إند فقط لتحديث تواريخ التعديل (updated_at) أو تسجيل سجلات التدقيق وحركات الحذف والتعديل (Audit Logging) يترك ثغرة خطيرة لو تم تعديل البيانات يدوياً من السيرفر. مشغلات Triggers ودوال PL/pgSQL المدمجة في PostgreSQL تعمل تلقائياً على مستوى المحرك لتسجيل كل حدث بدقة متناهية.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution Pipeline

1

دالة المشغل (Trigger Function)

دالة خاصة ترجع نوع TRIGGER وتتعامل مع المتغيرين السحريين NEW (البيانات الجديدة) و OLD (البيانات السابقة).

2

المشغلات قبل التعديل (BEFORE UPDATE)

تحديث حقل updated_at = NOW() تلقائياً قبل حفظ الصف على القرص.

3

الأعمدة المحسوبة المخزنة (STORED Generated Columns)

حساب قيم الأعمدة تلقائياً (مثل total = price * quantity) وحفظها مفهرسة دون أي تدخل برمجي.

🤔 سؤال تحدي كبار المهندسين:

ما هو الفرق بين المشغل على مستوى الصف (FOR EACH ROW) والمشغل على مستوى الجملة (FOR EACH STATEMENT)؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

المشغل FOR EACH ROW ينفذ دالة الـ Trigger لكل صف يتأثر بالاستعلام (إذا حدثت 100 صف ينفذ 100 مرة)، بينما FOR EACH STATEMENT ينفذ الدالة مرة واحدة فقط لكل أمر SQL بغض النظر عن عدد الصفوف المعدلة.

تشريح الكود المعماري سطراً بسطر · Annotated Code Anatomy

1: CREATE OR REPLACE FUNCTION update_timestamp() RETURNS TRIGGER AS $$ // دالة مشغل بلغة PL/pgSQL
2: BEGIN                                             // بداية الكتلة
3:   NEW.updated_at = CURRENT_TIMESTAMP;             // إسناد الوقت الحالي للنسخة الجديدة
4:   RETURN NEW;                                     // إرجاع الصف المعدل للحفظ
5: END; $$ LANGUAGE plpgsql;                         // نهاية الدالة

💼 سؤال إنترفيو للمهندسين الكبار (Senior Interview Question)

ما هي الأعمدة المحسوبة (Generated Columns) وما الفرق بين VIRTUAL و STORED في SQL الحديث؟

الأعمدة المحسوبة هي أعمدة تُحسب قيمتها تلقائياً من أعمدة أخرى في نفس الجدول؛ النوع `STORED` يحسب القيمة عند الإدخال/التعديل ويخزنها على القرص ويتيح فهرستها بـ B-Tree. والنوع `VIRTUAL` يحسب القيمة لحظياً عند كل قراءة دون استهلاك أي مساحة على القرص.
