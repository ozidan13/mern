Advanced SQL: Common Table Expressions (CTEs), Recursive CTEs & Window Functions

استعلامات SQL المتقدمة: الجداول المؤقتة (CTEs)، التكرار ودوال النوافذ (Window Functions)

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • هيكلة الاستعلامات المعقدة باستخدام Common Table Expressions (WITH clauses).
  • استخدام Recursive CTEs للبحث في الأشجار الهرمية والشبكات التنظيمية.
  • تطبيق Window Functions (ROW_NUMBER(), DENSE_RANK(), LAG(), LEAD()) مع جملة OVER (PARTITION BY ... ORDER BY ...).

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

كتابة استعلامات فرعية متداخلة (Nested Subqueries) يجعل الكود معقداً ومستحيلاً في الصيانة. توفر PostgreSQL ميزات SQL التحليلية الأقوى: تعبيرات الجداول العامة CTEs (WITH Queries) لتقسيم الاستعلام لمنطق مقروء، الـ Recursive CTEs للاستعلام في الهياكل الشجرية والشبكية (مثل الهيكل الوظيفي للأقسام)، ودوال النوافذ Window Functions (OVER, ROW_NUMBER, RANK) لحساب المعدلات التراكمية بدون تقليص الصفوف!

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
تعبيرات الجداول العامة (CTEs)

بناء جداول مؤقتة مسماة تُقرأ كأنها خطوات متسلسلة في الكود البرمجي.

2
دوال النوافذ (Window Functions)

حساب المجاميع والترتيبات عبر مجموعات فرعية (Partitions) مع الحفاظ على كل الصفوف الفردية.

3
الاستعلام العودي (WITH RECURSIVE)

المرور المتكرر على العلاقات الأبوية والأبناء حتى استيفاء شرط التوقف.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

ما هو الفرق الجوهري بين GROUP BY ودوال الـ Window Functions في SQL؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

الـ GROUP BY تجمع الصفوف المتعددة وتقلصها إلى صف واحد لكل مجموعة، بينما Window Functions تحسب القيم التراكمية والتحليلية مع الحفاظ على جميع الصفوف الفردية كاملة دون أي دمج أو تقليص.

تشريح الكود سطراً بسطر · Code Anatomy

1: WITH TopSales AS (                              // تعريف CTE الجدول المؤقت
2:   SELECT user_id, amount, ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY created_at DESC) as rn // ترقيم طلبات كل مستخدم
3:   FROM orders                                   // جدول الطلبات
4: )                                               // إغلاق CTE
5: SELECT * FROM TopSales WHERE rn = 1; -- يجلب آخر طلب لكل مستخدم حصراً // استعلام نهائي فائق النقاء

✅ الحل الهندسي الصحيح (Best Practice)

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): كيف يعمل WITH RECURSIVE في استعلام الأشجار الهرمية (مثل شجرة الفئات أو التعليقات المتداخلة)؟

يتكون من جزأين يربطهما `UNION ALL`: 1. `Non-Recursive Base Query`: يجلب جذور الشجرة (مثل الفئات الرئيسية التي ليس لها parent_id). 2. `Recursive Query`: ينضم مع نتيجة الـ CTE السابقة لجلب الأبناء المباشرين، ويكرر المحرك هذه الخطوة تلقائياً حتى لا يتبقى أي أبناء جدد.
