1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه التحويل البنكي الخزفي المحمي

تخيّل عملية تحويل مالي بين حسابين بنكيين: خصم 100$ من حسابك، ثم إضافة 100$ لحساب صديقك. إذا انقطعت الكهرباء أو تعطل السيرفر في المنتصف تماماً بعد الخصم وقبل الإيداع، فإن النظام العلائقي الموثوق (ACID) يضمن الذرية (Atomicity): إما أن تكتمل العمليتان معاً بنجاح، أو يتم التراجع عن الخصم بالكامل كأنه لم يحدث أبداً (Rollback)!

Definition & Purpose

PostgreSQL is an enterprise-grade object-relational database management system (ORDBMS). It structures data into mathematically formal relations (tables), strictly enforcing schemas, foreign key relationships, and full ACID transactional compliance.

قاعدة بيانات PostgreSQL هي المعيار الأقوى للأنظمة المالية والإنتاجية الكبرى. تضمن الحفاظ التام على سلامة البيانات عبر قيود الجداول (Constraints)، والمفاتيح الأجنبية (Foreign Keys)، وضمانات ACID الصارمة.

The 4 Pillars of ACID · الأركان الأربعة لسلامة المعاملات

A
Atomicity (الذرية: الكل أو لا شيء)

جميع خطوات المعاملة تنجح معاً بالكامل (Commit) أو تفشل وتلغى معاً بالكامل (Rollback).

C
Consistency (الاتساق وسلامة القيود)

لا يمكن للبيانات أن تخترق أي قيد مسبق (Unique, Foreign Key, Check Constraint).

I
Isolation (العزل بين العمليات المتزامنة)

المعاملات المتزامنة لا ترى التعديلات غير المؤكدة لبعضها البعض لمنع القراءات المشوهة.

D
Durability (المتانة والبقاء الدائم)

بمجرد تأكيد المعاملة (Commit)، تُحفظ البيانات على القرص ولا تفقد حتى في حالة انقطاع الكهرباء (WAL).

6. Practice & Common Mistakes · أخطاء شائعة

Missing Index on Foreign Key Columns
// ❌ SLOW (Full table scan on JOINs)
CREATE TABLE orders (
  user_id INT REFERENCES users(id)
);
// ✅ FAST (Indexed JOIN lookups)
CREATE TABLE orders ( user_id INT REFERENCES users(id) );
CREATE INDEX idx_orders_user_id ON orders(user_id);

التشخيص: لا ينشئ PostgreSQL فهارس تلقائية للمفاتيح الأجنبية، مما يسبب مسحاً كاملاً للجدول (Sequential Scan) عند تنفيذ عمليات الـ JOIN ما لم تنشئ الفهرس يدوياً.

Interview Question: Connection Pooling in PostgreSQL

Q: Why is Connection Pooling (e.g. PgBouncer) mandatory when connecting Node.js to PostgreSQL?

الإجابة: لأن PostgreSQL ينشئ عملية نظام منفصلة (Fork Process) لكل اتصال جديد تستهلك حوالي 10MB من الـ RAM. مجمّع الاتصالات (Connection Pool) يحافظ على عدد ثابت من الاتصالات المفتوحة ويعيد استخدامها بين آلاف طلبات Node.js بكفاءة.
