Automated Testing with Jest: Unit Tests, Mocks, Spies & Integration

الاختبارات المؤتمتة في Node.js بـ Jest: اختبارات الوحدات والمحاكاة (Mocks)

  • فهم هرم الاختبارات (Testing Pyramid): Unit vs Integration vs E2E.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

إطلاق كود للإنتاج بدون اختبارات مؤتمتة هو مغامرة انتحارية؛ أي تعديل بسيط في دالة قد يكسر ميزة أخرى في مكان بعيد تماماً دون أن تدري (Regression Bugs). إتقان كتابة اختبارات الوحدات (Unit Tests) واختبارات التكامل (Integration Tests) باستخدام Jest والمحاكاة البرمجية (Mocks & Spies) يعطيك ثقة حديدية في كل سطر كود تكتبه.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
هيكل الاختبار النظيف (AAA Pattern)

Arrange (تجهيز البيانات) ← Act (استدعاء الدالة) ← Assert (فحص النتيجة المتوقعة).

2
عزل التبعيات (Mocking)

استبدال استدعاءات الشبكة وقواعد البيانات بدوال وهمية سريعة قابلة للتوقع.

3
مراقبة الاستدعاءات (Spies)

التحقق من عدد مرات استدعاء دالة معينة والمعاملات التي تم تمريرها لها.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

ما هو الفرق بين jest.mock() و jest.spyOn()؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

الدالة jest.mock تستبدل الموديول بالكامل بدوال وهمية، بينما jest.spyOn تضع مراقباً على دالة محددة داخل كائن مع إمكانية الاحتفاظ بتنفيذها الأصلي أو محاكاته بـ mockImplementation.

تشريح الكود سطراً بسطر · Code Anatomy

1: test("should create user successfully", async () => { // تعريف اختبار غير متزامن
2:   const mockDb = jest.spyOn(User, "create").mockResolvedValue({ id: 1 }); // محاكاة حفظ قاعدة البيانات
3:   const result = await registerUser({ email: "test@dev.io" }); // استدعاء الدالة المختبرة
4:   expect(result.id).toBe(1);                    // فحص النتيجة
5: });                                             // نهاية الاختبار

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
test("database test", async () => { await realDb.deleteUsers(); }); /* اختبار يمسح بيانات حقيقية! */
✅ الحل الهندسي الصحيح (Best Practice)
test("mocked test", async () => { jest.spyOn(db, "delete").mockResolvedValue(true); }); /* معزول وآمن */

التشخيص الهندسي: اختبارات الوحدات يجب ألا تتصل بقواعد بيانات أو شبكات حقيقية لضمان سرعتها وعزلها الكامل.
