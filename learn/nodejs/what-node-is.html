Definition & Purpose

Node.js is an open-source, cross-platform JavaScript runtime environment built on Chrome's V8 JavaScript engine. It executes JavaScript code outside a web browser, enabling developers to build highly scalable network servers using event-driven, non-blocking I/O.

بيئة Node.js هي بيئة تشغيل برمجية تنقل جافاسكربت من المتصفح إلى السيرفر. تعتمد على محرك V8 لتحويل الكود إلى لغة الآلة، وتستخدم مكتبة libuv المكتوبة بلغة C++ للتعامل مع نظام التشغيل وإدارة العمليات غير المتزامنة بكفاءة خيالية.

الحجم الافتراضي لطاقم خيوط libuv هو 4 خيوط، ويمكن رفعه عبر متغيرات البيئة لمعالجة العمليات الثقيلة (مثل التشفير).

When does libuv use background threads?

ليست كل العمليات غير المتزامنة تستخدم الـ Thread Pool! طلبات الشبكة (Sockets) تتم إدارتها مباشرة عبر كيرنل نظام التشغيل (epoll / kqueue) بدون خيوط إضافية. بينما تستخدم خيوط libuv فقط للعمليات التي لا تدعم الـ Asynchronous في نظام التشغيل مثل: قراءة الملفات (fs)، التشفير (crypto)، وضغط البيانات (zlib).

6. Practice & Common Mistakes · أخطاء شائعة

Using Sync I/O in Production Request Handlers
// ❌ BLOCKING (Freezes all other incoming requests)
const data = fs.readFileSync('/large-file.json');
// ✅ NON-BLOCKING (Delegates to libuv)
const data = await fs.promises.readFile('/large-file.json');

التشخيص: استخدام الدوال المتزامنة (Sync) يحظر خيط الـ Event Loop ويمنع خدمة باقي المستخدمين حتى تكتمل القراءة من القرص.
