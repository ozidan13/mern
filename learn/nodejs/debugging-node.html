Node.js Debugging: Inspector Protocol, Chrome DevTools & Memory Leak Profiling

تنقيح أخطاء Node.js: بروتوكول Inspector وأدوات DevTools وتشخيص الذاكرة

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • تشغيل خوادم Node.js بوضع التنقيح node --inspect-brk وتوصيلها بـ DevTools.
  • استخدام Breakpoints و Watch Expressions وتتبع مكدس الاستدعاءات (Call Stack).

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

الاعتماد على console.log لتشخيص المشاكل المعقدة في خوادم Node.js يشبه البحث عن إبرة في كومة قش بالظلام! يوفر Node.js ميزة التنقيح الاحترافية عبر بروتوكول --inspect الذي يتيح ربط خادم الباك إند بأدوات Chrome DevTools أو VS Code لوضع نقاط التوقف (Breakpoints)، فحص قيم المتغيرات في الذاكرة لحظياً، والتقاط لقطات الـ Heap (Heap Snapshots) لكشف تسريبات الذاكرة.

تفعيل بروتوكول Inspector

Node.js يفتح منفذ WebSocket (افتراضياً 9229) للتواصل مع بيئات التنقيح.

2
إيقاف التنفيذ عند أول سطر (--inspect-brk)

المحرك يعلق التنفيذ فوراً قبل تشغيل الكود حتى يتم توصيل الـ Debugger.

3

مقارنة لقطتين من الذاكرة قبل وبعد إرسال 1000 طلب لكشف الكائنات التي لم يحذفها الـ Garbage Collector.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

ما هو الفرق بين أمر node --inspect وأمر node --inspect-brk؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

الأمر --inspect يشغل التطبيق ويبدأ الاستماع على منفذ الـ Debugger دون إيقاف الكود، بينما --inspect-brk يوقف تنفيذ الكود عند السطر الأول فوراً حتى تقوم بفتح أداة التنقيح والضغط على Resume.

تشريح الكود سطراً بسطر · Code Anatomy

1: # Terminal command to start debugging           // أمر التشغيل بالتنقيح
2: node --inspect-brk=0.0.0.0:9229 server.js       // فتح المنفذ 9229 للاتصال من DevTools
3: debugger;                                       // نقطة توقف برمجية داخل الكود

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
تشغيل --inspect في خوادم الإنتاج المفتوحة للإنترنت دون تقييد المنفذ (ثغرة تنفيذ كود عن بعد RCE!)
✅ الحل الهندسي الصحيح (Best Practice)
تشغيل --inspect فقط محلياً أو خلف SSH Tunnel محمي

التشخيص الهندسي: منفذ Inspector يتيح تنفيذ أي كود جافاسكربت بداخل السيرفر مباشرة، وإتاحته للعامة كارثة أمنية فادحة.
