02

إنشاء المسارات المطلقة بـ path.resolve()

تحويل سلسلة المسارات إلى مسار مطلق (Absolute Path) بالاعتماد على مجلد التشغيل الحالي process.cwd().

03

درع الحماية من اختراق المسارات (Path Traversal Guard)

فحص المسار المحسوب بـ path.normalize() والتأكد من أنه يبدأ حصراً بمسار المجلد المسموح به safeDir.startsWith().

04

استخراج الأجزاء الوصفية (Extname, Basename, Dirname)

استخراج امتداد الملف بدقة path.extname(file) واسم الملف بدون امتداد path.basename(file, ext).

05

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي كبار المهندسين:

ما الفرق في النتيجة بين path.join("/a", "/b") و path.resolve("/a", "/b")؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

دالة path.join("/a", "/b") تقوم بدمج السلسلتين وتنتج "/a/b". أما path.resolve("/a", "/b") فإنها تعتبر كل مسار يبدأ بـ "/" بمثابة جذر جديد (Root)، وتقوم بمعالجة المعاملات من اليمين لليسار، مما يجعل النتيجة تقتصر على "/b" فقط متجاهلة "/a"!

تشريح الكود المعماري سطراً بسطر · Annotated Code Anatomy

import path from "node:path";                        // استيراد وحدة المسارات ببادئة node: الرسمية
export function getSafeFilePath(baseFolder, userInput) { // دالة التحقق الأمني
  const safeBase = path.resolve(baseFolder);         // تثبيت المسار المطلق للمجلد الآمن
  const resolvedTarget = path.resolve(safeBase, userInput); // حساب المسار النهائي للهدف
  if (!resolvedTarget.startsWith(safeBase)) {        // فحص الحماية من الخروج من المجلد
    throw new Error("Access Denied: Path Traversal Attempt Detected"); // رمي خطأ أمني وحظر الطلب
  }                                                  // نهاية الفحص
  return resolvedTarget;                             // إرجاع المسار المحصن
}                                                    // نهاية الدالة

التشخيص الهندسي: الدمج اليدوي للسلاسل لا يعالج معاملات الرجوع للخلف (..) مما يسمح للمهاجم بالوصول لملفات النظام، بينما path.resolve مع startsWith يضمن الحبس داخل المجلد المسموح.

💼 سؤال إنترفيو للمهندسين الكبار (Senior Interview Question)

سؤال إنترفيو للمهندسين الكبار: ما هو الفرق بين path.sep و path.delimiter في Node.js؟

خاصية path.sep تمثل فاصل المجلدات داخل المسار الواحد (وهي \ في Windows و / في Linux/macOS). أما path.delimiter فتمثل الفاصل المستخدم بين مسارات متعددة في متغيرات البيئة مثل PATH (وهي الفاصلة المنقوطة ; في Windows والنقطتان : في Linux/macOS).
