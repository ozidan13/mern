Fetch API & REST Communication

بروتوكول Fetch: الاتصال بخوادم الـ REST APIs، معالجة الـ Headers، وإدارة أخطاء الشبكة

Teaches: Fetch API & AbortController Level 2 25 mins · دقيقة
Learning Objectives · أهداف الدرس
  • Understand the two-step Fetch stream resolution: headers received vs body parsed.
  • Master REST verbs: GET, POST, PUT, PATCH, DELETE and standard status codes.
  • Handle HTTP error statuses properly (why fetch() does NOT reject on 404/500).
  • Cancel in-flight requests safely using AbortController and timeouts.

1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه فتح الطرد البريدي على مرحلتين

عندما يصلك طرد بريدي عبر الشحن السريع، أنت أولاً تستلم الصندوق الخارجي وبطاقة الشحن (استلام الـ Headers والـ Status Code) — هنا يكتمل الوعد الأول لـ fetch(). لكن لكي تستخدم المنتج الذي بداخل الصندوق، عليك فتحه وتفريغ محتوياته (عملية res.json() أو res.text()) — وهي خطوة غير متزامنة ثانية لأن قراءة البيانات الضخمة تأتي كتدفق (Stream)!

Definition & Purpose

The fetch() method provides a modern, Promise-based interface for fetching resources asynchronously across the network. It replaced legacy XMLHttpRequest and natively integrates with Request/Response streams and modern Web Standards.

واجهة fetch() هي المعيار القياسي المدمج في المتصفحات وبيئات Node.js الحديثة لإجراء طلبات الشبكة. تعتمد بالكامل على الوعود (Promises) وتتعامل مع البيانات كتدفق بايتات مستمر (ReadableStream).

6. Practice & Common Mistakes · أخطاء شائعة

Missing Content-Type Header on POST Requests
// ❌ BROKEN (Server sees empty body)
fetch('/api/user', {
  method: 'POST',
  body: JSON.stringify({ name: 'Zaid' })
});
// ✅ FIXED (Server parses JSON body)
fetch('/api/user', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Zaid' })
});

التشخيص: بدون Content-Type: application/json، يتجاهل الـ Middleware في Express أو السيرفر قراءة الجسم ويعتبره فارغاً (req.body === undefined).

Interview Question: Handling Network Timeouts

Q: How do you enforce a strict 5-second timeout on a Fetch call?

الإجابة: عبر استخدام AbortSignal.timeout(5000) وتمريرها في خاصية signal داخل خيارات الـ fetch()، أو ربط setTimeout بـ controller.abort().
