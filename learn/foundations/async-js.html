Asynchronous JavaScript & Promises

البرمجة غير المتزامنة: الوعود (Promises)، الـ Microtasks، و Async/Await

Teaches: Promises & Event Loop Level 2 30 mins · دقيقة
Learning Objectives · أهداف الدرس

  • Understand the Microtask Queue priority over the Callback/Macrotask Queue.
  • Write clean asynchronous code with async/await and try...catch.

1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه جهاز الإنذار في المطعم (Buzzer)

عندما تطلب وجبة في مطعم مزدحم، لا يقف الكاشير متجمداً في انتظار طهي طعامك، بل يسلمك جهاز إنذار صغير (Buzzer) ويخدم الزبون التالي فوراً! هذا الجهاز هو الـ Promise: يبدأ في حالة انتظار (pending). عندما ينتهي الطهي، يهتز الجهاز وتستلم وجبتك (fulfilled)، أو يعتذر المطعم لعدم توفر المكونات (rejected).

Definition & Purpose

A Promise is an object representing the eventual completion or failure of an asynchronous operation. Rather than blocking the main thread, asynchronous tasks delegate I/O to system APIs and resolve callbacks via the Microtask queue.

الـ Promise هو كائن برمجي يمثل نتيجة عملية ستكتمل في المستقبل. يتيح لجافاسكربت تنفيذ العمليات الثقيلة (مثل استدعاءات الشبكة وقراءة الملفات) في الخلفية دون تجميد واجهة المستخدم (Non-blocking I/O).

5. Deep Dive & Complexity Analysis · التحليل والتعقيد

Promise.all Concurrent Time
O(max(T1, T2...))

تشغيل الوعود بالتوازي عبر Promise.all يستغرق زمن أطول طلب فقط بدلاً من جمع أزمنة الطلبات المتتالية.

Memory Overhead
O(N) Pending Promises

كل وعد معلق يحتفظ بذاكرة الدالة والـ Callbacks المرتبطة به في الـ Heap حتى تتم تسويته.

Promise Combinators: all vs allSettled vs race vs any
Method Resolves When Rejects When
Promise.all All promises fulfill Any single promise rejects (Fail-fast)
Promise.allSettled All promises settle (never rejects) Never
Promise.race First promise settles (win or lose) First promise rejects
Promise.any First promise fulfills All promises reject (AggregateError)

6. Practice & Common Mistakes · أخطاء شائعة

Sequential Await Waterfall (إبطاء الطلبات المستقلة)
// ❌ SLOW (Sequential waterfall)
const user = await fetchUser();
const posts = await fetchPosts();
// ✅ FAST (Parallel execution)
const [user, posts] = await Promise.all([
  fetchUser(), fetchPosts()
]);

التشخيص: انتظار طلبات غير معتمدة على بعضها بشكل متسلسل يضاعف زمن الانتظار بدون داعٍ.

8. Production Notes & Interviews · في بيئة العمل والمقابلات

Interview Question: Unhandled Promise Rejections

Q: Why does Node.js terminate processes on unhandled promise rejections?

الإجابة: لأن الخطأ غير المعالج يترك التطبيق في حالة غير محددة (Unclean state)، مما قد يسبب تسريبات ذاكرة أو تعطل المنطق، لذا تفرض البيئات الحديثة إنهاء العملية بأمان ما لم يتم التقاط الخطأ.
