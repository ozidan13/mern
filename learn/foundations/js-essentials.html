1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه حقيبة الظهر للطاهي (الـ Closure)

تخيّل طاهياً يعمل في مطبخ كبير (الدالة الخارجية). عندما يقرر الطاهي مغادرة المطبخ، فإنه يحزم بعض الأدوات والوصفات السرية الخاصة بذلك المطبخ داخل حقيبة ظهره الخاصة (الـ Closure). عندما يذهب إلى أي مكان آخر ويعمل بمفرده (الدالة الداخلية المعادة)، يمكنه في أي وقت فتح حقيبة ظهره واستخدام المتغيرات التي احتفظ بها من المطبخ الأصلي، حتى وإن تم إغلاق ذلك المطبخ بالكامل!

Definition & Purpose

JavaScript is a single-threaded synchronous language with non-blocking concurrency. Every piece of code executes inside an Execution Context containing Variable Environments, the Scope Chain, and the this binding.

جافاسكربت لغة أحادية الخيط (Single-Threaded)، أي أنها تنفذ أمراً واحداً فقط في اللحظة الواحدة. يقوم المحرك بإدارة التنفيذ عبر مكدس الاستدعاءات (Call Stack)، حيث يُنشئ لكل استدعاء دالة سياقاً خاصاً يحتوي على متغيراتها والارتباط بالسياقات الخارجية.

يقوم جامع القمامة (Garbage Collector) بحذف المتغيرات بمجرد أن تصبح غير قابلة للوصول (Unreachable). لكن المتغيرات المغلقة داخل Closure تظل محتفظة بمرجع نشط في الـ Heap، مما يمنع حذفها حتى تنتهي دورة حياة الدالة الداخلية.

6. Practice & Common Mistakes · أخطاء شائعة

The Classic "var in for-loop" Closure Bug
// ❌ BROKEN (All callbacks print 3)
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// ✅ FIXED (Prints 0, 1, 2)
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}

التشخيص: var يمتلك نطاق دالة (Function Scope)، فيشارك الجميع نفس المتغير، بينما let ينشئ نطاق كتلة (Block Scope) جديداً لكل تكرار.

Mini-Glossary · قاموس المصطلحات

Execution Context
البيئة الافتراضية التي يتم فيها تقييم وتنفيذ كود جافاسكربت.
Call Stack
مكدس يعتمد مبدأ (LIFO: يدخل آخراً يخرج أولاً) لتتبع مكان تنفيذ البرنامج واستدعاءات الدوال.
Closure
اقتران الدالة ببيئتها المعجمية (Lexical Environment)، مما يتيح لها الوصول لمتغيرات النطاق الخارجي حتى بعد انتهائه.
