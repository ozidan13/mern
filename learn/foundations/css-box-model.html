CSS Box Model, Flexbox Axis & Modern CSS Grid

نموذج الصندوق في CSS ومحاور Flexbox وشبكات Grid الحديثة

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • فهم حسابات الأبعاد الحقيقية في Content-Box مقابل Border-Box.
  • إتقان محاور Flexbox (Main Axis vs Cross Axis) والتوزيع الديناميكي.
  • بناء تخطيطات معقدة ثنائية الأبعاد باستخدام CSS Grid و minmax() و auto-fit.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

كتير من المطورين لما بيتعلموا CSS بيقضوا ساعات يضربوا في الـ padding والـ margin وتلاقي العنصر فجأة نزل في سطر جديد أو الشاشة ظهر فيها سكرول أفقي كارثي! السبب الجذري هو عدم فهم كيفية حساب الأبعاد في نموذج الصندوق (Box Model) والفرق بين content-box و border-box. بالإضافة للاعتماد على حلول قديمة زي float بدل محاور Flexbox الذكية وشبكات CSS Grid ثنائية الأبعاد.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
طبقات الـ Box Model الأربعة

المحتوى الداخلي (Content) ← الحشو الداخلي (Padding) ← الإطار (Border) ← الهامش الخارجي (Margin).

2
ضبط البنية عبر border-box

إجبار المتصفح على تضمين الـ padding والـ border داخل العرض الكلي (width).

3
التوزيع عبر Flexbox و Grid

استخدام Flexbox للعلاقات أحادية البعد (1D) و Grid للعلاقات ثنائية البعد (2D صفوف وأعمدة).

خاصية gap تعمل الآن بشكل أصلي داخل Flexbox تماماً كما في CSS Grid، وتضيف مسافات متساوية بين العناصر الفرعية دون الحاجة للـ margins السلبية أو فئات :last-child.

تشريح الكود سطراً بسطر · Code Anatomy

1: *, *::before, *::after {                        // استهداف جميع العناصر ومولدات المحتوى
2:   box-sizing: border-box;                       // ضمان أن الـ width يشمل الـ padding والـ border
3:   margin: 0;                                    // تصفير الهوامش الافتراضية للمتصفح
4: }                                               // إغلاق القاعدة العامة

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
.container { display: flex; } .item { width: 50%; margin: 10px; } /* يسبب انكسار السطر */
✅ الحل الهندسي الصحيح (Best Practice)
.container { display: flex; gap: 20px; } .item { flex: 1; } /* توزيع مرن دقيق */

التشخيص الهندسي: الجمع بين العرض النسبي 50% والهوامش الثابتة بدون calc يفيض عن عرض الحاوية ويكسر التخطيط.

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): متى تفضل استخدام CSS Grid ومتى تختار Flexbox في بناء واجهات الإنتاج؟

نستخدم Flexbox عندما يكون التخطيط أحادي البعد (1D) سواء صف أو عمود ويكون المحتوى هو الحاكم لمساحة العنصر (Content-First). ونستخدم CSS Grid عندما يكون التخطيط ثنائي الأبعاد (2D صفوف وأعمدة متقاطعة) وتكون الشبكة هي الحاكمة لمواقع العناصر (Layout-First).
