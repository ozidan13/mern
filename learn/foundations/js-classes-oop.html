ES6 Classes, Private Fields (#), Inheritance & Static Methods

الفئات الكلاسيكية في ES6، الحقول الخاصة (#) والوراثة في V8

  • إتقان الوراثة عبر extends و super() والخصائص الساكنة (Static).

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

فئات ES6 Classes في جافاسكربت هي في الأساس "سكر تركيبي" (Syntactic Sugar) فوق نموذج الـ Prototypes، لكنها أضافت معايير هندسية صارمة زي الحقول والأساليب الخاصة الحقيقية المنفذة على مستوى المحرك (#privateField) والدوال الساكنة (static) وكتل التهيئة الساكنة. محاولة الوصول للحقول الخاصة من خارج الفئة تفشل على مستوى المحرك، مما يوفر كبسلة (Encapsulation) حقيقية 100%.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
دالة البناء constructor واستدعاء super()

عند وراثة فئة، يجب استدعاء super() أولاً قبل لمس this لحجز مثيل الفئة الأب.

2
الحقول الخاصة الحقيقية (#)

الحقول التي تبدأ بعلامة # غير قابلة للوصول من خارج الفئة حتى عبر Object.keys أو reflection.

3
الخصائص الساكنة (Static Properties)

خصائص ترتبط بالفئة نفسها كـ Blueprint ولا تتكرر في النسخ المُنشأة (Instances).

تشريح الكود سطراً بسطر · Code Anatomy

1: class AdminUser extends User {                  // وراثة فئة AdminUser من فئة User الأساسية
2:   #permissions = [];                            // حقل خاص مشفر على مستوى المحرك
3:   constructor(name, perms) {                    // دالة البناء
4:     super(name);                                // تهيئة الفئة الأب أولاً (إجباري)
5:     this.#permissions = perms;                  // إسناد الحقل الخاص
6:   }                                             // نهاية البناء
7: }                                               // نهاية الفئة

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
class User { _password = "123"; } /* مجرد اتفاقية شكلية ويمكن قراءتها وتعديلها بسهولة! */
✅ الحل الهندسي الصحيح (Best Practice)
class User { #password = "123"; } /* كبسلة خاصة حقيقية محمية بالـ V8 */

التشخيص الهندسي: البادئة _ هي مجرد اتفاق بين المطورين ولا تمنع أي شخص أو كود خارجي من قراءة الحقل الحساس، بينما # محمية برمجياً.

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): ما هو الفرق الجوهري بين الدوال العادية المعرفة داخل Class والـ Static Methods؟

الدوال العادية (Instance Methods) يتم وضعها على `ClassName.prototype` وتكون متاحة لكل كائن تم إنشاؤه عبر `new`. بينما الـ `static methods` يتم وضعها مباشرة على كائن الفئة نفسه `ClassName` ولا ترثها النسخ، وتُستخدم كـ Utility Functions مثل `Array.from()` أو `Object.keys()`.
