ES6 Classes, Private Fields (#), Inheritance & Mixins

فئات ES6 Classes، الحقول الخاصة (#)، التوريث ومزج السلوكيات (Mixins)

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • فهم كيف تُترجم فئات ES6 Classes إلى Prototypal Inheritance تحت الغطاء (Syntactic Sugar).
  • تطبيق الكبسلة الصارمة (True Encapsulation) باستخدام الحقول والأساليب الخاصة بالرمز #.
  • إتقان التوريث عبر extends واستدعاء المشيد الأب عبر super().
  • تطبيق نمط Mixins لتجميع السلوكيات وتفادي مشاكل التوريث المتعدد الصلب.

المشكلة الهندسية والسياق الواقعي · The Architectural Problem

رؤية الواقع العملي والنموذج الذهني · Real-World Context & Mental Model

عندما أضافت لجنة TC39 كلمة class في معيار ES6، رحب مبرمجو لغات OOP التقليدية بالخطوة واعتبروا أن جافاسكريبت أصبحت لغة كلاسيكية. لكن الحقيقة أن Classes في جافاسكريبت هي مجرد "غلاف جمالي" (Syntactic Sugar) فوق نموذج الـ Prototypal Inheritance! ومع ذلك، التطورات الحديثة في ES2022+ أضافت ميزات ثورية حقيقية لم تكن موجودة من قبل: الحقول الخاصة الصارمة (Private Fields) باستخدام رمز الـ #، والـ Static Blocks للتهيئة المعقدة. قبل إضافة #privateField، كان المبرمجون يضعون شرطة سفلية _password كتحذير شكلي فقط، لكن أي كود خارجي كان يستطيع قراءتها وتعديلها بسهولة. في هذا الدرس، هنتعلم إزاي نبني معمارية كلاسات قوية ونظيفة، إزاي نحمي البيانات الحساسة بكبسلة حقيقية على مستوى الـ Bytecode، وإزاي نستخدم نمط الـ Mixins لبناء كائنات مرنة متعددة القدرات.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution Pipeline

01

تشريح الـ Constructor والتهيئة

دالة constructor() هي المكان الوحيد المخصص لتهيئة النسخة (Instance Initialization) وربط الخصائص المبدئية.

02

الحقول الخاصة الحقيقية (#Private Identifiers)

الحقول والأساليب التي تبدأ بـ # يتم حظر الوصول إليها تماماً من خارج الـ Class على مستوى محرك V8 ولا يمكن قراءتها حتى بـ bracket notation.

03

التوريث واستدعاء super()

عند وراثة كلاس بـ extends، يجب استدعاء super() قبل استخدام كلمة this في المشيد الفرعي لتهيئة الـ Prototype الأب.

04

الخصائص والكتل الساكنة (Static Fields & Blocks)

الخصائص الساكنة static تتبع الكلاس نفسه ولا تتكرر على كل Instance، وتستخدم للـ Factory Methods والإعدادات العامة.

05

نمط Mixins لتركيب السلوكيات (Composition over Inheritance)

دوال تستقبل فئة كمدخل وتُرجع فئة جديدة مضافاً إليها أساليب وسلوكيات محددة بدون التقيد بشجرة توريث أحادية.

سيرمي المحرك خطأ ReferenceError: Must call super constructor in derived class before accessing "this". في جافاسكريبت، الكلاس الأب هو المسؤول عن تخصيص الذاكرة لكائن this، ولا يتم ربط this بالكلاس الفرعي إلا بعد اكتمال تنفيذ مشيد الأب عبر super().

تشريح الكود المعماري سطراً بسطر · Annotated Code Anatomy

class Service {                                      // تعريف الفئة الأساسية
  #apiKey;                                           // حقل خاص حقيقي لا يمكن قراءته خارج الكلاس
  static instanceCount = 0;                          // خاصية ساكنة مشتركة على مستوى الفئة
  constructor(apiKey) {                              // مشيد الفئة
    this.#apiKey = apiKey;                           // تعيين الحقل الخاص
    Service.instanceCount++;                         // تحديث العداد الساكن
  }                                                  // نهاية المشيد
  get key() { return this.#apiKey.slice(0, 4) + "****"; } // Getter لتوفير قراءة مقنعة وآمنة
}                                                    // نهاية الفئة

معرض الأخطاء الشائعة والحلول الهندسية · Production Mistakes Gallery

❌ الكود المسبب للأعطال (Anti-Pattern)
// خطأ شائع: الاعتماد على التوريث الصلب العميق متعدد الطبقات
class Animal {}
class Mammal extends Animal {}
class FlyingMammal extends Mammal {}
class Bat extends FlyingMammal {} // شجرة توريث صلبة تنكسر عند إضافة خفاش لا يطير!
✅ الحل الهندسي القياسي (Best Practice)
// الحل الهندسي: استخدام التركيب (Composition & Mixins)
const CanFly = (Base) => class extends Base { fly() { return "Flying!"; } };
const CanEcho = (Base) => class extends Base { echo() { return "Sonar active!"; } };

class Bat extends CanFly(CanEcho(Object)) {} // دمج السلوكيات بمرونة

التشخيص الهندسي: التوريث الطبقي العميق (Deep Inheritance Hierarchy) يربط الكود بصلابة ويجعل التعديلات المستقبلية مستحيلة (Fragile Base Class Problem)، بينما Composition يتيح مرونة فائقة.

💼 سؤال إنترفيو للمهندسين الكبار (Senior Interview Question)

سؤال إنترفيو للمهندسين الكبار: ما هي الكتل الساكنة (Static Initialization Blocks) المضافة في ES2022 وما هي المشكلة التي حلتها؟

الكتل الساكنة static { ... } تسمح بكتابة كود تنفيذي معقد (مثل try/catch أو التحقق من البيئة أو مشاركة بيانات خاصة مع دوال خارجية) أثناء مرحلة تحميل الفئة (Class Evaluation). قبل ES2022، كان لا يمكن تنفيذ أكثر من سطر تهيئة واحد لكل خاصية ساكنة، ولم يكن ممكناً مشاركة الحقول الخاصة #private مع دوال مساعدة خارج الكلاس دون كشفها للعامة.
