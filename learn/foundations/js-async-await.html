Async/Await Control Flow, Sequential vs Parallel & Error Guards

التحكم في العمليات اللاتزامنية بـ Async/Await والتنفيذ المتوازي

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • فهم كيفية عمل async/await داخلياً كـ Generators و Promises تحت الكابوت.
  • القضاء التام على ظاهرة الـ Async Waterfall باستخدام Promise.all و Promise.allSettled.
  • بناء حراس أخطاء مركزية أنيقة تمنع انهيار التطبيق عند فشل الاتصالات الشبكية.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

الـ async/await هي طريقة خيالية لكتابة كود لاتزامني يتقرأ ويتفهم كأنه كود متزامن سطر بسطر. لكن أكبر كارثة بيقع فيها المطورين هي تحويل الطلبات المتوازية المستقلة إلى شلال انتظار متسلسل بطيء (Async Waterfall)! لما تعمل await getUser() وبعدها await getProducts() وأنت مش محتاج مخرجات الأول في التاني، أنت ضاعفت زمن استجابة الصفحة مرتين بدون أي مبرر هندسي!

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
الدوال غير المتزامنة تُرجع Promise دائماً

أي دالة تسبقها كلمة async تُغلف قيمتها المعادة تلقائياً داخل Promise.resolve().

2
تعليق التنفيذ المؤقت (Yielding)

كلمة await توقف تنفيذ دالة الـ async فقط وتسمح للـ Event Loop بمعالجة باقي أحداث الصفحة دون تجميد.

3
المعالجة المتوازية (Parallel Execution)

إطلاق كل الوعود معاً في نفس اللحظة وانتظارها دفعة واحدة بـ Promise.all.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

ماذا يحدث إذا فشل وعد واحد (Rejected) داخل مصفوفة Promise.all()؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

الدالة Promise.all تتبع مبدأ "الكل أو الفشل الفوري" (Fail-Fast)؛ إذا فشل وعد واحد فإنها ترفض المصفوفة كاملة فوراً وتتجاهل باقي الوعود حتى لو نجحت، ولتجنب هذا نستخدم Promise.allSettled().

تشريح الكود سطراً بسطر · Code Anatomy

1: async function loadDashboard() {                // إعلان دالة غير متزامنة
2:   const [stats, alerts] = await Promise.all([   // إطلاق وجلب الطلبات بشكل متوازي متزامن
3:     fetchStats(),                               // طلب الإحصائيات
4:     fetchAlerts()                               // طلب التنبيهات
5:   ]);                                           // انتظار اكتمال الاثنين معاً بأسرع وقت
6: }                                               // نهاية الدالة

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
const u = await getUser(); const p = await getPosts(); /* شلال بطيء يجمع وقت الاثنين */
✅ الحل الهندسي الصحيح (Best Practice)
const [u, p] = await Promise.all([getUser(), getPosts()]); /* تشغيل متوازي يأخذ وقت الأطول فقط */

التشخيص الهندسي: الانتظار المتسلسل للطلبات المستقلة هو العدو الأول لأداء تطبيقات الويب ويزيد الـ Latency بلا فائدة.

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): كيف يتعامل محرك V8 مع كتل try/catch داخل دوال async عند حدوث Promise Rejection؟

عندما تضع `await` داخل `try/catch`، إذا تم رفض الـ Promise (Rejected) يقوم محرك V8 بتحويل الـ Rejection إلى Exception حقيقي يمكن التقاطه داخل كتلة `catch(err)` تماماً كالكود المتزامن المتصل.
