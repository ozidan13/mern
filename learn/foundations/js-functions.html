Function Declarations, Expressions, Arrow Functions & Hoisting

دوال جافاسكريبت: الإعلانات، التعبيرات، الدوال السهمية ورفع المتغيرات (Hoisting)

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • فهم سلوك الـ Hoisting الدقيق بين Function Declarations و Function Expressions و let/const.
  • تشريح كلمة this والفرق الجوهري بين الربط الديناميكي (Dynamic this) والربط المعجمي (Lexical this) في الدوال السهمية.
  • إتقان استخدام call(), apply(), و bind() للتحكم في سياق التنفيذ وتمرير المعاملات.
  • تطبيق مبادئ الدوال النقية (Pure Functions) وتفادي الآثار الجانبية (Side Effects).

المشكلة الهندسية والسياق الواقعي · The Architectural Problem

رؤية الواقع العملي والنموذج الذهني · Real-World Context & Mental Model

الدوال في جافاسكريبت تُعامل كـ "مواطنين من الدرجة الأولى" (First-Class Citizens)، يعني تقدر تخزن دالة في متغير، تمررها كمعامل لدالة تانية، أو ترجعها من دالة تانية كـ Closure. لكن مع هذه القوة الهائلة، بتظهر واحدة من أكثر النقاط المسببة للإحباط: "هو كلمة this بتشير لمين دلوقتي؟". كم مرة كتبت Event Handler في زرار، واستدعيت جواه this.setState() أو this.userName وتفاجأت بـ Cannot read properties of undefined؟ أو كم مرة حاولت تستدعي دالة قبل سطر تعريفها ولقيتها اشتغلت في حالة Function Declaration، لكن ضربت خطأ ReferenceError: Cannot access before initialization لما حولتها لـ Arrow Function؟ في هذا الدرس، هنفكك سياق التنفيذ (Execution Context)، وهنعرف بالمللي إزاي محرك V8 بيتعامل مع الـ Memory Allocation أثناء مرحلة الـ Creation Phase، والفرق القاطع بين أنواع الدوال المختلفة.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution Pipeline

01

مرحلة الرفع وإنشاء السياق (Creation Phase & Hoisting)

يتم رفع Function Declarations بجسمها الكامل للذاكرة. المتغيرات المعرفة بـ var ترفع بقيمة undefined، بينما let و const توضع في منطقة Temporal Dead Zone (TDZ).

02

الربط الديناميكي لكلمة this

في الدوال العادية، قيمة this تتحدد عند لحظة الاستدعاء (Call-Site) وليس لحظة الكتابة، وتعتمد على الكائن الموجود قبل النقطة user.getName().

03

الربط المعجمي في الدوال السهمية (Lexical this)

الدوال السهمية Arrow Functions لا تملك this أو arguments خاصة بها؛ بل ترثها تلقائياً من النطاق الخارجي المعجمي المحيط بها.

04

التحكم الصريح في السياق: call, apply, bind

call تمرر المعاملات مفصولة، apply تمرر المعاملات في مصفوفة، و bind تنشئ دالة جديدة تماماً مربوطة بالسياق المحدد للاستدعاء المستقبلي.

05

المعاملات الافتراضية والـ Rest Parameters

استخدام ...args لتجميع المعاملات غير المحدودة في مصفوفة حقيقية بدلاً من كائن arguments القديم.

🤔 سؤال تحدي كبار المهندسين:

لماذا لا يمكن استخدام الدالة السهمية (Arrow Function) كـ Constructor مع الكلمة المفتاحية new؟ وماذا يحدث إذا حاولت تنفيذ new (() => {})؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

الدوال السهمية لا تملك خاصية الـ prototype ولا تملك دالة بناء داخلية [[Construct]] في مواصفات محرك جافاسكريبت. محاولة استدعائها مع new ستؤدي فوراً لرمي خطأ TypeError: (intermediate value) is not a constructor.

تشريح الكود المعماري سطراً بسطر · Annotated Code Anatomy

function regularAdd(a, b = 0) {                      // Function Declaration مع معامل افتراضي
  return a + b;                                      // إرجاع القيمة صراحة
}                                                    // تخضع للـ Hoisting بالكامل
const arrowAdd = (a, b) => a + b;                 // Arrow function مع Implicit Return
const boundFunction = regularAdd.bind(null, 5);      // تثبيت المعامل الأول جزئياً (Currying/Partial App)
const logAll = (...args) => {                     // استخدام Rest Parameters لتجميع المعاملات
  args.forEach(arg => console.log(arg));          // المعاملات مصفوفة حقيقية تدعم forEach
};                                                   // نهاية الدالة

معرض الأخطاء الشائعة والحلول الهندسية · Production Mistakes Gallery

❌ الكود المسبب للأعطال (Anti-Pattern)
// خطأ شائع: استخدام Arrow Function كـ Method داخل Object Literal
const profile = {
  username: "Zidan",
  sayHi: () => {
    console.log("Hi, " + this.username); // this هنا تشير للـ Window أو Global وليس profile!
  }
};
✅ الحل الهندسي القياسي (Best Practice)
// الحل الصحيح: استخدام Method Shorthand العادي
const profile = {
  username: "Zidan",
  sayHi() {
    console.log("Hi, " + this.username); // this تشير لكائن profile بنجاح
  }
};

التشخيص الهندسي: الدوال السهمية لا تنشئ سياق this خاص بها، بل تأخذ السياق المحيط بالـ Object Literal (والذي يكون غالباً النطاق العام Global/Window).

💼 سؤال إنترفيو للمهندسين الكبار (Senior Interview Question)

سؤال إنترفيو للمهندسين الكبار: ما هي المنطقة الميتة الزمنية (Temporal Dead Zone - TDZ) وكيف تؤثر على الدوال المعرفة بـ let و const؟

الـ TDZ هي الفترة الزمنية بين دخول النطاق (Scope Entry) وسطر التنفيذ الفعلي الذي يتم فيه الإعلان عن المتغير وتهيئته. المتغيرات المعرفة بـ let و const يتم حجز مكان لها في الذاكرة أثناء الـ Creation Phase، لكن لا يُسمح بالوصول إليها مطلقاً قبل سطر تعريفها، ومحاولة قراءتها ترمي ReferenceError. لذلك فإن الدوال المعرفة كـ Function Expressions عبر const myFn = () => {} لا يمكن استدعاؤها قبل سطر تعريفها لأنها تكون محاصرة داخل الـ TDZ.
