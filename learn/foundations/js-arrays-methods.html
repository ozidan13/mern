Array Pipeline: Map, Filter, Reduce, FlatMap & Performance

خط أنابيب المصفوفات: Map, Filter, Reduce والتحسين الأدائي

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • إتقان دوال التحويل الوظيفية: map, filter, reduce, flatMap, find, some, every.
  • التمييز الصارم بين الدوال المعدلة (In-Place Mutators) والدوال النقية في إدارة الحالة (Immutability).
  • تحسين أداء معالجة المصفوفات الضخمة وتجنب إنشاء كائنات وسيطة في الـ Heap.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

معالجة مصفوفات البيانات الكبيرة (آلاف أو ملايين السجلات) تتطلب فهماً عميقاً للفرق بين الدوال التي تعدل المصفوفة الأصلية (Mutating Methods زي splice, sort, push) والدوال النقية غير المعدلة (Non-mutating زي map, filter, toSorted). تسلسل استدعاء .filter().map().filter() ينشئ مصفوفات مؤقتة وسيطة في الذاكرة تهلك الـ Garbage Collector، وفي هذا الدرس سنتعلم كيف ندمجها في خط أنابيب reduce ذري فائق السرعة.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
التحويل بدون تعديل الأصل (Immutability)

دوال map و filter تنشئ مصفوفة جديدة تماماً وتترك المصفوفة الأصلية نظيفة دون مساس.

2
قوة المحرك الشامل reduce

تجميع مصفوفة كاملة في كائن أو رقم أو خريطة في ممر مسح واحد (Single Pass O(n)).

3
دوال ES2023 الآمنة (toSorted, toReversed)

استخدام النسخ الآمنة الحديثة التي تضمن عدم تعديل المصفوفة الأصلية.

🤔 سؤال تحدي المهندسين:

ما هو الفرق بين Array.prototype.map() و Array.prototype.flatMap()؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

الدالة flatMap تطبق دالة التحويل على كل عنصر ثم تسطح النتيجة (Flatten) بمقدار مستوى واحد (depth: 1)، وهي مكافئة لـ .map().flat() ولكنها أكثر كفاءة وسرعة ولا تنشئ مصفوفة وسيطة.

تشريح الكود سطراً بسطر · Code Anatomy

1: const sum = items.reduce((acc, curr) => {    // بدء دالة التجميع مع المجمع acc والعنصر الحالي curr
2:   return acc + curr.price;                      // إضافة السعر التراكمي
3: }, 0);                                          // تحديد القيمة الابتدائية 0 للمجمع (إجباري لتجنب الأخطاء)

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
const sorted = users.sort(); /* تعدل مصفوفة users الأصلية وتسبب bugs في React! */
✅ الحل الهندسي الصحيح (Best Practice)
const sorted = [...users].sort(); /* أو users.toSorted() في المتصفحات الحديثة */

التشخيص الهندسي: دالة sort() الكلاسيكية تعدل المصفوفة في مكانها (In-Place Mutation)، مما يكسر مبدأ الـ Immutability في React و Redux.
