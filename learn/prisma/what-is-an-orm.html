1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه المترجم الفوري الصارم بين لغتين

أنت في تطبيقك تفكر بلغة كائنات جافاسكربت و TypeScript (Objects & Types)، بينما قاعدة البيانات تفكر بلغة الجداول والعلاقات والـ SQL (Tables & Relational Algebra). Definition & Purpose

An Object-Relational Mapper (ORM) bridges the gap between object-oriented code and relational database tables. Prisma is a next-generation ORM that features an intuitive schema definition language, automated type generation, and a high-performance Rust-powered query engine.

أداة Prisma ORM هي الطبقة المسؤولة عن ربط تطبيق Node.js بقواعد البيانات. توفر ملف مخطط موحد (schema.prisma) تصف فيه الجداول والعلاقات، وتولد لك عميل استعلامات عالي الكفاءة يضمن الأمان النوعي التام (Type Safety).

What causes the famous "N+1 Queries Problem" in backend APIs, and how does Prisma prevent it?

ما هو سبب مشكلة N+1 في استعلامات قواعد البيانات وكيف يتفاداها Prisma؟

تحدث مشكلة N+1 عند جلب N مستخدم ثم تنفيذ استعلام منفصل داخل حلقة تكرار لكل مستخدم لجلب مقالاته (مما يرسل 101 استعلاماً للسيرفر). يحلها Prisma بدمجها في استعلامين سريعين فقط باستخدام WHERE id IN (...) عبر include: { posts: true }.

4. Code Anatomy · تشريح الكود

1: const user = await prisma.user.findUnique({ 2: where: { email: 'omar@example.com' }, 3: include: { 4: posts: { where: { published: true } } 5: } 6: });

السطر 1: دالة findUnique تبحث فقط في الحقول المفهرسة بقيد الفرادة (Unique Constraints).

السطر 3 & 4: خاصية include تدمج المقالات المرتبطة بالمستخدم تلقائياً مع تطبيق فلترة المقالات المنشورة فقط.

Prisma Schema DSL Syntax Example 
model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  name      String?
  posts     Post[]
  createdAt DateTime @default(now())
}

model Post {
  id        Int      @id @default(autoincrement())
  title     String
  published Boolean  @default(false)
  authorId  Int
  author    User     @relation(fields: [authorId], references: [id])
}

6. Practice & Common Mistakes · أخطاء شائعة

Instantiating Multiple PrismaClient Instances
// ❌ EXHAUSTS DB CONNECTIONS
// in every route file:
const prisma = new PrismaClient();
// ✅ SINGLETON PATTERN
// db.ts export singleton instance:
export const prisma = new PrismaClient();

التشخيص: إنشاء كائن new PrismaClient() جديد في كل ملف ينشئ مجمّع اتصالات منفصلاً، مما يستنزف سعة اتصالات قاعدة البيانات بسرعة ويوقف السيرفر.

Q: How do you gracefully handle Prisma's P2002 error code in a production Express API?

الإجابة: عبر فحص error.code === 'P2002' في الـ Catch Block أو معالج الأخطاء المركزي، وإرجاع رد 409 Conflict للمستخدم يوضح الحقل المكرر بدلاً من إرجاع خطأ 500 غامض.
