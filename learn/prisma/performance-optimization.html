Prisma Performance Optimization: Solving N+1 Queries, Select Projection & Index Tuning

تحسين أداء بريزما: حل مشكلة استعلامات N+1 وتحديد الأعمدة وضبط الفهارس

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • فهم وتشخيص كارثة استعلامات N+1 وكيف يعالجها Prisma Query Engine تلقائياً.
  • تطبيق الإسقاط الدقيق للأعمدة (Select Projection) لتوفير الذاكرة وسرعة نقل الشبكة.
  • ضبط فهارس @@index و @@unique لتسريع استعلامات العلاقات والتصفية.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

واحدة من أخطر مشاكل الـ ORM في كل لغات البرمجة هي كارثة استعلامات N+1 Queries: عندما تجلب 100 مستخدم ثم تدور في حلقة تكرار لجلب طلبات كل مستخدم، يقوم الـ ORM بإرسال 101 طلب لقاعدة البيانات بدلاً من استعلامين مجمعين! في هذا الدرس هنتعلم كيف يحل بريزما مشكلة N+1 تلقائياً عبر تقنية DataLoader-style Batching وكيف نضبط الـ Select Projection لتحقيق أقصى سرعة.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

كيف تفعل تسجيل استعلامات الـ SQL ومقاييس زمن التنفيذ في عميل بريزما محلياً؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

عبر تمرير خيار log أثناء التهيئة: new PrismaClient({ log: [ { emit: "event", level: "query" } ] }) ثم الاستماع للحدث prisma.$on("query", e => console.log(e.query, e.duration + "ms")).

تشريح الكود سطراً بسطر · Code Anatomy

1: const prisma = new PrismaClient({               // تهيئة العميل مع فاحص الأداء
2:   log: [{ emit: "event", level: "query" }]      // بث أحداث استعلامات SQL
3: });                                             // نهاية التهيئة
4: prisma.$on("query", (e) => {                 // الاستماع لزمن التنفيذ
5:   if (e.duration > 100) console.warn(`Slow Query (${e.duration}ms):`, e.query); // تنبيه للاستعلامات البطيئة
6: });                                             // نهاية المراقب

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
استدعاء await prisma.order.findMany داخل حلقة users.map(async u => ...)!
✅ الحل الهندسي الصحيح (Best Practice)
استخدام prisma.user.findMany({ include: { orders: true } }) في استعلام واحد مجمع

التشخيص الهندسي: الاستعلام داخل حلقات التكرار يطلق مئات الطلبات للـ Database ويهلك اتصال الخادم.

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): كيف تؤثر دقة Select Projection على أداء استعلامات البوستجريس في بريزما؟

عندما تحدد أعمدة محددة عبر `select` بدلاً من جلب الجدول كاملاً: 1. تقلل حجم البيانات المنقولة عبر الشبكة من الداتابيز للسيرفر. 2. تقلل استهلاك الذاكرة في Node.js. 3. تمكن محرك PostgreSQL من استخدام الاستعلامات المغطاة (Covered Index Queries) وإرجاع النتائج مباشرة من شجرة الفهرس دون قراءة صفحات الجدول على القرص.
