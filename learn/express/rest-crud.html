Building a Production REST CRUD API

بناء واجهة REST CRUD إنتاجية: معالجة المدخلات (Params & Query)، التحقق من البيانات، وتوحيد هيكل الردود

Learning Objectives · أهداف الدرس

  • Extract and validate Route Parameters (req.params) and Query Strings (req.query).
  • Enforce HTTP Status Code semantics: 200, 201, 204 No Content, 400, 404, 422.

1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه أمين السجل المدني والملفات

بناء REST API يشبه نظام أمين السجلات والملفات الحكومية: إذا أردت إنشاء سجل جديد، تقدم استمارة كاملة (POST → 201 Created).
إذا أردت الاستعلام عن ملف برقم هويته، تطلبه بالرقم (GET /records/:id → 200 OK).
إذا أردت تعديل حقل العنوان فقط دون تغيير باقي الملف، تقدم تعديلاً جزئياً (PATCH → 200 OK).
وإذا أردت إتلاف الملف تماماً، يحذفه الأمين ويعطيك إشعار نجاح فارغ (DELETE → 204 No Content)!

Definition & Purpose

A RESTful CRUD API (Create, Read, Update, Delete) structures server endpoints around nouns (resources) rather than verbs. Clients manipulate resources using standard HTTP verbs, predictable URI patterns, and standardized JSON payloads.

واجهات REST CRUD هي النمط القياسي العالمي لبناء واجهات الـ Backend. تعتمد على جعل عناوين الـ URL تعبر عن موارد وأسماء جمع (مثل /api/v1/courses)، واستخدام أفعال الـ HTTP للتعبير عن العملية المطلوبة.

The Standard REST CRUD Matrix · جدول معايير العمليات الأربع

POST
Create: POST /api/courses → 201 Created

إنشاء عنصر جديد في قاعدة البيانات وإرجاع الكائن المنشأ حديثاً متضمناً معرّفه الفريد (id).

GET
Read: GET /api/courses/:id → 200 OK

استرجاع بيانات عنصر محدد بواسطة معرّفه، أو إرجاع 404 Not Found إذا لم يكن موجوداً.

PATCH
Update: PATCH /api/courses/:id → 200 OK

تعديل جزئي للحقول المرسلة فقط دون إلزام العميل بإعادة إرسال الكائن بالكامل (عكس PUT).

DEL
Delete: DELETE /api/courses/:id → 204 No Content

حذف العنصر نهائياً وإرجاع استجابة فارغة مع كود 204 No Content لتأكيد الإزالة.

Predict Before You Run · توقّع النتيجة أولاً

What is the semantic difference between HTTP PUT and HTTP PATCH?

ما هو الفرق الدلالي الدقيق بين أسلوب PUT وأسلوب PATCH في معايير REST؟

PUT يستبدل الكائن بالكامل (Full Replacement)، بينما PATCH يعدل الحقول المحددة فقط ويحتفظ بباقي الحقول (Partial Update).

4. Code Anatomy · تشريح الكود

1: app.delete('/api/courses/:id', (req, res) => { 2: const courseId = Number(req.params.id); 3: const index = courses.findIndex(c => c.id === courseId); 4: if (index === -1) return res.status(404).json({ error: 'Course not found' }); 5: courses.splice(index, 1); 6: res.status(204).send(); 7: });

السطر 2: استخراج المعامل الديناميكي من req.params.id وتحويله لرقم (Number) للمطابقة.

السطر 4: فحص وجود السجل أولاً وإرجاع رمز 404 Not Found المناسب إذا لم يوجد.

السطر 6: إرجاع 204 No Content بعد نجاح الحذف بدون إرسال جسم استجابة.

5. Deep Dive & Complexity Analysis · التحليل والتعقيد

CRUD Lookup Complexity
O(1) with Index / Map

البحث بمعرف الـ ID في قواعد البيانات المفهرسة (Indexed Primary Key) يتم بزمن فوري O(1) أو O(log N).

Payload Validation
Schema Guard (Zod)

يجب دائماً تمرير req.body عبر مكتبة فحص مخططات (مثل Zod) قبل لمس قاعدة البيانات لمنع أخطاء الـ Type Injection.

6. Practice & Common Mistakes · أخطاء شائعة

Returning 200 OK on Resource Creation
// ❌ NON-STANDARD (200 for POST creation)
res.json(newRecord);
// ✅ REST STANDARD (201 Created)
res.status(201).json(newRecord);

التشخيص: معايير REST توجب إرجاع رمز 201 Created عند نجاح إنشاء مورد جديد، وليس 200 OK العامة.

Mini-Glossary · قاموس المصطلحات

Route Parameters (req.params)
المتغيرات المضمنة في مسار الـ URL (مثل :id في /users/:id) لتحديد مورد فريد.
Query String (req.query)
المعاملات الاختيارية المضافة في نهاية العنوان بعد علامة ? لفلترة وترتيب البيانات (مثل ?sort=asc&limit=10).

8. Production Notes & Interviews · في بيئة العمل والمقابلات

Interview Question: Idempotency in REST APIs

Q: What does Idempotency mean, and which HTTP verbs are Idempotent?

الإجابة: الخاصية اللاإرادية (Idempotency) تعني أن تكرار إرسال نفس الطلب عدة مرات متتالية يؤدي إلى نفس النتيجة بالضبط على الخادم.
- أفعال حيادية: GET, PUT, DELETE.
- أفعال غير حيادية (Non-idempotent): POST (لأن تكراره ينشئ سجلات مكررة جديدة).
