Multi-Part Form Data & Secure File Uploads with Multer

معالجة الملفات المرفوعة وبيانات Multipart/form-data بمكتبة Multer

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • تكوين وسيط Multer مع خيارات التخزين DiskStorage و MemoryStorage.
  • تطبيق فلترة صارمة لأنواع الملفات (MIME Type Filtering) للصور فقط.
  • تقييد الحجم الأقصى للملفات وتسمية الملفات بأسماء فريدة غير قابلة للتصادم.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

رفع الصور والملفات في تطبيقات الويب يختلف عن إرسال بيانات JSON؛ البيانات تأتي بصيغة multipart/form-data وتحتاج لمعالجة خاصة للتدفقات الثنائية (Binary Streams). ترك رفع الملفات بدون قيود أمنية يسمح للمخترقين برفع ملفات سكربتات خبيثة (.php أو .sh) أو ملفات ضخمة بحجم جيجابايت تفجر مساحة القرص الصلب وتوقف السيرفر تماماً!

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
تفكيك الـ Multipart Stream

Multer يعترض تدفق البيانات الثنائية ويفصل الحقول النصية عن بايتات الملفات.

2
فلترة الأنواع والامتدادات

فحص file.mimetype والتأكد من أنه يطابق صورة حقيقية (image/jpeg, image/png).

3
التخزين الآمن وإعادة التسمية

حفظ الملف باسم فريد يحتوي على Timestamp و UUID لمنع استبدال ملفات مستخدمين آخرين.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

لماذا يعتبر فحص file.mimetype غير كافٍ وحده بنسبة 100% للتأكد من أمان الملف المرفوع؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

لأن الـ MIME Type يُرسل من المتصفح في ترويسات الطلب ويمكن للمخترق تزييفه بسهولة؛ الأمان التام يتطلب فحص التوقيع السحري للبايتات (Magic Bytes) للملف باستخدام مكتبة مثل file-type أو معالجة الصورة وإعادة ضغطها عبر Sharp.

تشريح الكود سطراً بسطر · Code Anatomy

1: const upload = multer({                         // إعداد وسيط الرفع
2:   limits: { fileSize: 5 * 1024 * 1024 }, // 5MB limit // تقييد الحجم الأقصى
3:   fileFilter: (req, file, cb) => {           // فلترة الأنواع
4:     if (file.mimetype.startsWith("image/")) cb(null, true); // قبول الصور فقط
5:     else cb(new AppError("Only images allowed", 400), false); // رفض الملفات الأخرى
6:   }                                             // نهاية الفلتر
7: });                                             // جاهز للاستخدام

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
upload.single("file"); /* بدون تحديد limits أو fileFilter يسمح برفع ملفات خبيثة ضخمة */
✅ الحل الهندسي الصحيح (Best Practice)
upload.single("avatar"); /* مع limits و fileFilter صارم */

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): متى تختار MemoryStorage ومتى تختار DiskStorage عند تكوين Multer؟

نستخدم `MemoryStorage` عندما نحتاج لمعالجة الصورة في الذاكرة أولاً (مثل إعادة تحجيمها وضغطها عبر مكتبة Sharp) قبل رفعها مباشرة إلى خدمة تخزين سحابية مثل AWS S3 أو Cloudinary. ونستخدم `DiskStorage` عندما نريد حفظ الملفات مباشرة كملفات دائمة على القرص الصلب للسيرفر.
