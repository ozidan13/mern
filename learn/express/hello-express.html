الميزة الثورية في Express 5.2

في الإصدارات القديمة (Express 4)، لو حصل خطأ أو Rejected Promise جوه دالة مسار غير متزامنة (async/await)، كان السيرفر بيعلق ومبيعرفش يمسك الخطأ إلا لو كتبت try...catch يدوي في كل مسار وناديت next(err)! في Express 5، أصبح السيرفر يدعم الوعود تلقائياً (Native Async Error Catching)، فأي استثناء يرمى في أي مسار async يتم توجيهه أوتوماتيكياً لحارس الأخطاء المركزي دون أن يسقط السيرفر!

7. أخطاء شائعة وفخاخ يقع فيها الجميع · Common Pitfalls

إرسال الرد مرتين (Cannot set headers after they are sent)
// ❌ خطأ: محاولة إرسال ردين في نفس الطلب يرمي استثناء قاتلاً
if (!user) res.status(404).send('Not Found');
res.json(user); // ينفذ أيضاً!
// ✅ سليم: استخدام return لإنهاء تنفيذ الدالة فور إرسال الرد
if (!user) return res.status(404).send('Not Found');
return res.json(user);

التشخيص الهندسي: بروتوكول HTTP يسمح برد واحد فقط لكل طلب، ومحاولة إرسال ترويسات بعد إغلاق الـ Socket تؤدي لانهيار المعالج.
