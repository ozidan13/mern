Real-Life Analogy · تشبيه مأمور البريد وموجه الطرود

إذا كان خادم Node.js الخام (node:http) هو بمثابة مبنى البريد الأساسي حيث تستلم الطرود كقطع خام وتحتاج لتحليل النصوص والمسارات يدوياً بـ if...else معقدة، فإن Express.js هو مأمور البريد الذكي (Router): بمجرد وصول الطرد، يقرأ العنوان ونوع الخدمة (GET / POST) ويوجهه فوراً إلى المكتب المخصص له دون أي تعقيد يدوي!

Definition & Purpose

Express.js is a fast, unopinionated, minimalist web framework for Node.js. It wraps the raw HTTP server with powerful routing mechanisms, middleware support, and intuitive response formatting utilities.

إطار عمل Express.js هو الإطار الأكثر انتشاراً لبناء خوادم الويب والـ REST APIs في بيئة Node.js. يوفر بنية مرنة وخفيفة لتنظيم المسارات ومعالجة الطلبات وإرجاع الردود بتنسيق JSON بطريقة مقروءة وقياسية.

6. Practice & Common Mistakes · أخطاء شائعة

Calling res.send() multiple times (Headers already sent error)
// ❌ CRASHES (Cannot set headers after they are sent)
if (!user) res.status(404).send('Not found');
res.json(user);
// ✅ FIXED (Use return to exit handler)
if (!user) return res.status(404).send('Not found');
res.json(user);

التشخيص: دالة res.json() ترسل الرد للعميل وتغلق الاتصال، ومحاولة إرسال رد ثانٍ تسبب استثناء ERR_HTTP_HEADERS_SENT.

Interview Question: Dynamic Port Binding

Q: Why should you always use process.env.PORT instead of hardcoding port 3000?

الإجابة: منصات الاستضافة السحابية (مثل AWS، Railway، Render) تعين منافذ متغيرة ديناميكياً لكل حاوية (Container). لذا يجب كتابة: const PORT = process.env.PORT || 3000; لضمان استقرار التشغيل محلياً وسحابياً.
