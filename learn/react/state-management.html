Global State Management with Zustand: Stores, Selectors & Slices

إدارة الحالة العامة بمكتبة Zustand: المتاجر والمحددات والشرائح

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • إنشاء متجر Zustand عام بحجم أقل من 1KB ودون Context Providers.
  • تطبيق محددات الحالة الدقيقة (Selectors) لمنع إعادة الرسم العشوائي.
  • تقسيم المتاجر المعقدة إلى شرائح مستقلة (Slices Pattern).

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

مكتبات إدارة الحالة القديمة مثل Redux الكلاسيكي كانت تتطلب كتابة مجلدات من ملفات Actions و Reducers و Types المعقدة (Boilerplate Hell). مكتبة Zustand قدمت ثورة هندسية: متجر عام خفيف يعتمد على Hook بسيط بدون الحاجة لتغليف التطبيق بـ Providers، ويدعم التحديد الدقيق (Atomic Selectors) بحيث لا يعاد رسم المكون إلا إذا تغيرت الخاصية التي يشترك فيها بالضبط!

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
المتجر خارج شجرة ريآكت (External Store)

Zustand يحتفظ بالحالة كـ Closure خارجي ويرتبط بريآكت عبر useSyncExternalStore.

2
الاشتراك الذري (Atomic Selectors)

المكون يمرر دالة اختيار state => state.user فلا يعاد رسمه إذا تغير cart.

3
الدوال غير المتزامنة الأصلية

كتابة دوال async داخل المتجر مباشرة وتحديث الحالة بـ set() دون الحاجة لـ Thunks معقدة.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

لماذا لا تحتاج مكتبة Zustand لتغليف التطبيق بـ Provider في رأس شجرة المكونات؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

لأن متجر Zustand هو كائن جافاسكربت نقي خارج شجرة ريآكت (Module Singleton)، ويشترك المكون فيه مباشرة عبر الـ Subscription الداخلي.

تشريح الكود سطراً بسطر · Code Anatomy

1: export const useCartStore = create((set) => ({ // إنشاء المتجر
2:   items: [],                                    // الحالة
3:   addItem: (item) => set((s) => ({ items: [...s.items, item] })), // دالة التحديث
4:   clearCart: () => set({ items: [] })        // تفريغ السلة
5: }));                                            // نهاية المتجر

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
const { items, clearCart } = useCartStore(); /* استهلاك بدون Selector يعيد الرسم مع أي تغيير */
✅ الحل الهندسي الصحيح (Best Practice)
const items = useCartStore(state => state.items); /* اشتراك ذري بالـ items فقط */

التشخيص الهندسي: عدم استخدام الـ Selectors يفقد Zustand أهم ميزة فيها ويعيد رسم المكون عند تغير أي خاصية غير مستخدمة في المتجر.
