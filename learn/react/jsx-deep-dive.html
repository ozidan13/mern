المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

المطور المبتدئ لما بيشوف كود JSX بيفكر إنه بيكتب كود HTML عادي جوه جافاسكربت! الحقيقة الصادمة إن المتصفح ميعرفش إيه هو الـ JSX ومبيفهموش إطلاقاً. الـ JSX هو مجرد "سكر تركيبي" (Syntactic Sugar) لأشجار كائنات برمجية بسيطة. قبل ما المتصفح يشوف سطر كود واحد، محول زي Babel أو SWC بيحول كل وسم لنداء React.createElement أو لدالة _jsx() الحديثة.

1: const el = <h1 className="title">Hello</h1>; // وسم JSX بسيط
2: const el = _jsx("h1", { className: "title", children: "Hello" }); // الترجمة لكائن VDOM خفيف

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
return ( <h1>Title</h1> <p>Desc</p> ); /* خطأ: لا يمكن إرجاع قيمتين */
✅ الحل الهندسي الصحيح (Best Practice)
return ( <> <h1>Title</h1> <p>Desc</p> </> ); /* تغليف بـ Fragment */

التشخيص الهندسي: دوال جافاسكربت لا تستطيع إرجاع أكثر من قيمة واحدة، ولهذا يجب تجميع العناصر في جذر واحد أو وسم Fragment.
