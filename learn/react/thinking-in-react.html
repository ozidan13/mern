1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه قطع الليغو وشلال المياه

بناء الواجهات في React يشبه تماماً التركيب بقطع الليغو (Lego Bricks): كل زر، بطاقة، أو شريط بحث هو قطعة مستقلة ذات مسؤولية واحدة (Single Responsibility). أما تدفق البيانات فيشبه شلال المياه الهابط: تتدفق البيانات (Props) دائماً من المكون الأب إلى المكونات الأبناء في اتجاه واحد من الأعلى للأسفل، ولا يمكن للماء أن يصعد تلقائياً إلا إذا ضغط الابن على زر التنبيه لطلب التحديث (Event Callback).

Definition & Purpose

React is a declarative, component-based library for building user interfaces. Instead of manually mutating DOM nodes step-by-step (Imperative UI), you declare what the UI should look like for a given state (UI = fn(State)), and React synchronizes the real DOM automatically.

تعتمد ريآكت على مبدأ الواجهات التقريرية (Declarative UI). بدلاً من كتابة أوامر تعديل الـ DOM يدوياً وبشكل مجهد (Imperative)، أنت تصف فقط شكل الواجهة بناءً على الحالة الحالية، ويتولى المحرك مطابقة وتحديث شجرة العناصر تلقائياً وبأعلى كفاءة.

The 5 Steps of Thinking in React · خطوات بناء أي تطبيق

1
1. Break UI into Component Hierarchy

ارسم مربعات حول كل جزء في التصميم وحدد المكونات الفرعية وشجرة العلاقات (Parent / Child).

2
2. Build a Static Version (Props only)

ابنِ الهيكل بدون أي State تفاعلية، مستخدماً الـ Props فقط لتمرير البيانات وعرض الواجهة.

3
3. Identify the Minimal State Representation

حدد فقط البيانات المتغيرة التي لا يمكن حسابها من قيم أخرى، وتجنب تكرار وتخزين البيانات المحسوبة.

4
4. Find Where State Should Live (Lifting State Up)

ضع الـ State في أقرب أب مشترك (Common Ancestor) بين جميع المكونات التي تحتاج قراءتها أو تعديلها.

State Checklist: Is it really State?
  1. هل يتم تمريرها من الأب عبر Props؟ ← ليست State.
  2. هل تظل ثابتة ولا تتغير مع الوقت؟ ← ليست State.
  3. هل يمكن حسابها من State أو Props أخرى؟ ← ليست State (احسبها لحظياً).

6. Practice & Common Mistakes · أخطاء شائعة

Duplicating Props into State (مزامنة الحالة المزدوجة)
// ❌ REDUNDANT STATE
const [fullName, setFullName] = useState(props.first + ' ' + props.last);
// ✅ DERIVED STATE
const fullName = `${props.first} ${props.last}`;

التشخيص: نسخ الـ Props داخل الـ State يؤدي إلى تعطل التزامن عند تغير الـ Props الأصلية في الأب.
