1. Core Concept & Mechanics · الفكرة الأساسية

Real-Life Analogy · تشبيه السبورة والنسخة الجديدة

تخيّل أن لديك سبورة بيضاء يكتب عليها الرسام لوحة. المتغيرات العادية داخل الدالة هي مثل الملاحظات المكتوبة بالطبشور السريع الزوال — بمجرد انتهاء تنفيذ الدالة، تُمسح السبورة تماماً وتبدأ من الصفر في كل مرة! أما useState فهو بمثابة خزنة خاصة بالمكون خارج السبورة: عندما تطلب تغيير قيمة، فإنك لا تعدل الورقة القديمة بقلم حبر، بل تعطي الرسام ورقة جديدة كلياً ليضعها على السبورة في الرسمة القادمة. هذا هو جوهر الـ Immutability.

Definition & Purpose

In React, useState is the fundamental hook that declares a state variable preserved across re-renders. It returns a tuple containing the current state value and a setter function that schedules a reconciliation pass.

دالة useState هي الـ Hook الأساسي الذي يمنح المكون ذاكرة خاصة. تعيد الدالة مصفوفة ثنائية (Tuple): العنصر الأول هو القيمة الحالية للحالة، والعنصر الثاني هو دالة التحديث التي تخبر React بجدولة إعادة رسم المكون.

Why It Exists · لماذا لا نستخدم متغيرات JavaScript العادية؟

المتغيرات العادية (مثل let count = 0) تفقد قيمتها عند انتهاء تنفيذ الدالة، كما أن تغيير قيمتها لا يعطي أي إشارة لـ React ليقوم بتحديث شجرة الـ DOM. يحل useState هاتين المشكلتين معاً: الاحتفاظ بالذاكرة وإطلاق دورة إعادة الرسم (Re-render).

If you call setCount(count + 1) three times in one event handler, what is the final value?

إذا استدعيت setCount(count + 1) ثلاث مرات متتالية، ما هي القيمة النهائية؟

القيمة ستزيد بمقدار 1 فقط! لأن كل استدعاء يقرأ نفس قيمة count المغلقة في دالة الحدث (Stale Closure). لحل ذلك استخدم: setCount(c => c + 1).

6. Practice & Common Mistakes · تمارين وأخطاء شائعة

Common Mistakes Gallery · معرض الأخطاء الشائعة

Direct State Mutation · تعديل الحالة مباشرة
// ❌ BROKEN
user.name = 'Omar';
setUser(user);
// ✅ FIXED
setUser({ ...user, name: 'Omar' });

التشخيص: لأن المرجع user === user لم يتغير، يعتبر React أنه لا يوجد أي تعديل ويتجاهل إعادة الرسم.

Immutability (عدم القابلية للتعديل المباشر)

Automatic Batching (دمج التحديثات التلقائي)
ميزة في React تدمج عدة استدعاءات لتحديث الحالة في دورة رسم واحدة لتعزيز الأداء.
