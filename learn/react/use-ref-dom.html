useRef: Mutable Value Persistence & Direct DOM Node Access

هوك useRef: الاحتفاظ بالقيم المتغيرة والوصول المباشر للـ DOM

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • استخدام useRef كصندوق أمانات (Mutable Box) يحتفظ بالقيم دون إطلاق Re-renders.
  • الوصول لعناصر الـ DOM وتطبيق التركيز التلقائي والتمرير (Focus & Scroll).
  • تخزين معرفات المؤقتات (Timers & Intervals) وقيم الـ Previous Props.

المشكلة الهندسية والسياق الواقعي

رؤية الواقع العملي · Real-World Context & Mental Model

هوك useRef في ريآكت له وظيفتان رئيسيتان: الأولى هي الوصول المباشر لعقد الـ DOM الحقيقية (للتركيز أو قياس الأبعاد)، والثانية والأهم هي الاحتفاظ بقيم متغيرة عبر عمليات إعادة الرسم (Renders) دون إطلاق إعادة رسم جديدة عند تعديلها!

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution

1
كائن المرجع المستقر { current }

ريآكت تعيد دائماً نفس كائن المرجع بين كل عمليات الرسم.

2
تعديل current لا يطلق Render

تحديث ref.current = val يتم فورياً في الذاكرة دون المساس بجدولة المكون.

3
ربط العقدة عند الـ Commit Phase

ريآكت تسند عنصر الـ DOM لـ ref.current بمجرد رسمه وتسنده لـ null عند الحذف.

تحدي التوقع قبل التشغيل · Predict Before You Run

🤔 سؤال تحدي المهندسين:

لماذا يحظر قراءة أو كتابة ref.current أثناء مرحلة الرسم (Render Phase) مباشرة؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

لأن مرحلة الرسم يجب أن تكون نقية 100% وبدون آثار جانبية؛ تعديل ref أثناء الـ Render يجعل سلوك المكون غير متوقع مع ميزات Concurrent Rendering.

تشريح الكود سطراً بسطر · Code Anatomy

1: const inputRef = useRef(null);                  // إنشاء المرجع
2: useEffect(() => { inputRef.current?.focus(); }, []); // التركيز على الحقل بعد اكتمال الرسم
3: return <input ref={inputRef} />;          // ربط المرجع بالعنصر

معرض الأخطاء الشائعة والحل النموذجي · Mistakes Gallery

❌ الكود الخاطئ المسبب للكوارث (Anti-Pattern)
ref.current = 100; /* كتابة المرجع داخل جسم المكون مباشرة */ return <div>...</div>;
✅ الحل الهندسي الصحيح (Best Practice)
useEffect(() => { ref.current = 100; }, []); /* كتابة المرجع داخل Effect أو Event Handler */

التشخيص الهندسي: تعديل المراجع أثناء الـ Render يكسر نقاء المكونات ويسبب أخطاء في الـ Concurrent Mode.

💬 سؤال إنترفيو للمهندسين الكبار (Senior Interview Q&A): كيف تقيس قيمة الـ Prop السابقة (Previous Value) باستخدام useRef؟

نعرف `const prevValue = useRef()` وداخل `useEffect(() => { prevValue.current = val; }, [val])` نحدث المرجع؛ فيكون `prevValue.current` أثناء الـ Render يحمل القيمة السابقة دائماً.
