Conditional Rendering Patterns: The 0 && Trap, Polymorphic Components & Early Returns

أنماط العرض الشرطي في ريآكت: فخ الرقم صفر (0 && Trap)، المكونات المتعددة الأشكال والـ Early Returns

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • تجنب الفخ الكارثي الشهير 0 && وظهور الرقم 0 على الشاشة للمستخدم.
  • إتقان استخدام نمط الإرجاع المبكر (Early Returns / Guard Clauses) لتنظيف شجرة الـ JSX.
  • بناء مكونات متعددة الأشكال (Polymorphic Components) تدعم حالات Loading و Error و Empty و Success.
  • استخدام الجداول الشرطية (Lookup Tables / Object Maps) كبديل متفوق لسلاسل Ternary المتشعبة.

المشكلة الهندسية والسياق الواقعي · The Architectural Problem

رؤية الواقع العملي والنموذج الذهني · Real-World Context & Mental Model

العرض الشرطي (Conditional Rendering) هو عصب بناء التطبيقات الديناميكية: "لو المستخدم مسجل دخول اعرض صورته، لو التطبيق بيحمل اعرض Skeleton، لو مفيش بيانات اعرض Empty State". لكن في ريآكت، هناك خطأ كلاسيكي يقع فيه حتى المطورون المحترفون وهو ما يعرف بـ "The Zero Bug": تخيل أنك كتبت كود لعرض قائمة الرسائل: 

{messages.length && <MessagesList items={messages} />}
لو مصفوفة الرسائل فارغة (messages.length = 0)، المتصفح مش هيخفي القائمة ويسكت... المتصفح هيعرض رقم 0 قبيح جداً في منتصف الصفحة للمستخدمين! السبب أن عامل && في جافاسكريبت يرجع القيمة اليسرى مباشرة إذا كانت Falsy، وبما أن الرقم 0 هو قيمة صالحة للرسم في JSX، فإن ريآكت تقوم برسمه كنص! في هذا الدرس، هنتعلم القواعد الذهبية لتفادي أخطاء العرض الشرطي، إزاي نكتب Guard Clauses نظيفة، وإزاي نبني State Machines بصرية باستخدام Lookup Tables.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution Pipeline

01

قاعدة البوليان الصارمة لعامل &&

حول الطرف الأيسر دائماً إلى قيمة منطقية حقيقية Boolean(items.length) أو items.length > 0 قبل استخدام && لمنع رسم الأصفار والنصوص الفارغة.

02

نمط الإرجاع المبكر (Early Return Pattern)

معالجة حالات التحميل والأخطاء في بداية الدالة وإرجاع JSX مخصص قبل الدخول في المنطق الرئيسي للمكون.

03

العامل الثلاثي للتبديل الثنائي (Ternary Operator)

استخدام condition ? : عندما يكون هناك مساران إجباريان متبادلان مع الحفاظ على مقروئية الكود.

04

خريطة الكائنات للحالات المتعددة (Lookup Map Pattern)

تخزين المكونات في كائن { idle: , loading: , error: } كبديل نظيف لسلاسل switch المتشعبة.

05

إخفاء العناصر بصرياً مقابل إلغاء تركيبها (Display None vs Unmounting)

فهم متى تفرغ المكون من الذاكرة (Unmount لحذف الـ State) ومتى تخفيه بـ CSS (للاحتفاظ بمدخلات المستخدم).

ما الفرق في سلوك الـ Component State عندما تخفي مكوناً باستخدام CSS display: none مقارنة بإخفائه عبر العرض الشرطي condition && ؟

اضغط هنا للكشف عن الإجابة والتحليل الهندسي الدقيق

مع display: none، يظل المكون مركباً في الـ DOM وشجرة الـ Fiber، ويحتفظ بجميع حالاته (useState, input values, timers). أما مع العرض الشرطي، تقوم ريآكت بإلغاء تركيب المكون بالكامل (Unmounting)، مما يحذف الـ State الخاص به من الذاكرة ويعيد تهيئته من الصفر عند ظهوره مجدداً.

تشريح الكود المعماري سطراً بسطر · Annotated Code Anatomy

function ProductList({ products, isLoading, error }) { // مكون يستقبل حالات متعددة
  if (isLoading) return <SkeletonLoader />;    // حارس الإرجاع المبكر للتحميل
  if (error) return <ErrorMessage error={error} />; // حارس الإرجاع المبكر للأخطاء
  if (products.length === 0) return <EmptyState />; // حارس الحالة الفارغة
  return (                                           // العرض الرئيسي الناجح
    <ul className="product-grid">              // قائمة المنتجات
      {products.map(p => <ProductCard key={p.id} item={p} />)} // رسم العناصر
    </ul>                                      // إغلاق القائمة
  );                                                 // نهاية الـ JSX
}                                                    // نهاية المكون

معرض الأخطاء الشائعة والحلول الهندسية · Production Mistakes Gallery

❌ الكود المسبب للأعطال (Anti-Pattern)
// خطأ شائع مسبب لظهور الرقم صفر على الشاشة
<div>
  {cartItems.length && <CheckoutButton count={cartItems.length} />}
</div>
✅ الحل الهندسي القياسي (Best Practice)
// الحلول الهندسية الصحيحة:
<div>
  {cartItems.length > 0 && <CheckoutButton count={cartItems.length} />}
  {/* أو باستخدام التحويل المنطقي: */}
  {Boolean(cartItems.length) && <CheckoutButton count={cartItems.length} />}
</div>

التشخيص الهندسي: عندما تكون قيمة cartItems.length = 0، فإن التعبير 0 && يُرجع 0 مباشرة. ورغم أن boolean false لا يُرسم في JSX، فإن الرقم 0 يُعامل كنص صالح ويظهر على الشاشة.

💼 سؤال إنترفيو للمهندسين الكبار (Senior Interview Question)

سؤال إنترفيو للمهندسين الكبار: كيف تؤثر تقنية Conditional Rendering على دقة حسابات مؤشر أداء الويب Cumulative Layout Shift (CLS)؟

التبديل المفاجئ بين المكونات (مثلاً من Loading Spinner صغير إلى بطاقة بيانات ضخمة بعد اكتمال الـ Fetch) يؤدي إلى قفزات بصرية في تخطيط الصفحة (Layout Shifts) مما يضر بدرجة الـ CLS في معايير جوجل Core Web Vitals. لتفادي ذلك معمارياً، نستخدم Skeleton Loaders تحاكي أبعاد ومساحة المكون النهائي بالضبط، أو نثبت ارتفاع الحاوية min-height مسبقاً.
