مكتبة Mongoose 8: المخططات، خطافات الـ Middleware والاستعلامات الخفيفة (Lean)

🎯 الأهداف الهندسية لهذا الدرس (Learning Objectives)

  • تعريف مخططات Mongoose Schemas مع القواعد الصارمة والخصائص الافتراضية والتحقق المخصص.
  • استخدام خطافات ما قبل وما بعد الحفظ (Pre/Post Save Middleware) لتشفير كلمات المرور.
  • تحسين سرعة استعلامات القراءة بنسبة 5x باستخدام .lean().

المشكلة الهندسية والسياق الواقعي · The Architectural Problem

رؤية الواقع العملي والنموذج الذهني · Real-World Context & Mental Model

التعامل مع MongoDB عبر مكتبة Mongoose يوفر أمان المخططات والتحقق التلقائي والـ Hooks. لكن أكبر فخ أدائي يقع فيه المطورون هو استدعاء User.find() لقراءة 10,000 مستند لعرضهم في جدول؛ يقوم Mongoose بتغليف كل مستند بكائن Mongoose Document كامل يحتوي على دوال التغيير والمراقبة والـ Getters، مما يستهلك 500MB من الـ Heap! الحل السحري هو تفعيل .lean() لإرجاع كائنات جافاسكربت نقية O(1) فائقة السرعة.

كيف تعمل المنظومة خطوة بخطوة · Mechanics & Execution Pipeline

المخططات والنماذج (Schemas & Models)

بناء هيكل البيانات وتطبيق القواعد الصارمة (Required, Unique, Enum, Min/Max).

2

خطافات الـ Middleware (Pre-save)

اعتراض عملية الحفظ لتجزئة كلمة المرور تلقائياً عبر bcrypt قبل وصولها لقاعدة البيانات.

3

الاستعلامات الخفيفة بـ lean()

تجاوز كائنات Mongoose الثقيلة وإرجاع Plain JavaScript Objects لعمليات القراءة السريعة.

1: userSchema.pre("save", async function(next) {     // خطاف ما قبل الحفظ

3:   this.password = await bcrypt.hash(this.password, 12); // تشفير كلمة المرور تلقائياً
4: });                                               // نهاية الخطاف

معرض الأخطاء الشائعة والحلول الهندسية · Production Mistakes Gallery

❌ الكود المسبب للأعطال (Anti-Pattern)
const users = await User.find(); /* استعلام قراءة ثقيل يستهلك الذاكرة بدون داعٍ */
✅ الحل الهندسي القياسي (Best Practice)
const users = await User.find().lean(); /* استعلام خفيف مثالي لواجهات القراءة */

التشخيص الهندسي: عدم استخدام lean في عمليات القراءة البحتة (Read-Only Endpoints) يهدر الذاكرة ويبطئ الـ API.

💼 سؤال إنترفيو للمهندسين الكبار (Senior Interview Question)

ما هي الـ Virtual Properties في Mongoose وفيمَ تفيد في تصميم النماذج؟

هي خصائص وهمية محسوبة يمكن قراءتها من النموذج (مثل `fullName` الذي يدمج `firstName` و `lastName`) لكنها لا تُخزن في قاعدة البيانات ولا تستهلك مساحة على القرص، وتُحسب لحظياً عند الحاجة.
