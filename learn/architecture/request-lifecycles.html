المعمارية ثلاثية الطبقات (Controller - Service - Repository)

أكبر فخ يقع فيه المطور المبتدئ هو كتابة استعلامات قاعدة البيانات ومنطق التشفير وفحص الصلاحيات كلها معاً داخل دالة app.post('/buy')! المهندس المحترف يفصل النظام لـ 3 طبقات:
1. Controller Layer: مسؤولة فقط عن استلام طلب الـ HTTP والتحقق من المدخلات وإرجاع كود الحالة.
2. Service Layer (Business Logic): العقل المفكر (حساب الخصومات، إرسال إشعارات الإيميل، ومنطق الأعمال النقي).
3. Repository / Data Access Layer: المسؤولة عن التحدث مع Prisma وقاعدة البيانات.

5. تشريح هيكل المشروع الإنتاجي المتماسك · Code Anatomy

1: src/ 2: ├── controllers/ # HTTP request parsing & status code mapping 3: ├── services/ # Pure business logic & payment integrations 4: ├── repositories/ # Prisma data queries & schema abstractions 5: ├── middlewares/ # Auth guards, CORS, rate limits & error guards 6: └── lib/ # Singleton instances (prisma client, redis)

الأسطر 2-4: الفصل الصارم بين الـ Controllers والـ Services والـ Repositories يتيح لك اختبار منطق الأعمال (Unit Testing) بسهولة دون تشغيل سيرفر HTTP أو قاعدة بيانات حية.

// ✅ سليم: تفويض المهمة لـ OrderService النقي

});

قاموس المصطلحات الأساسية · Mini-Glossary

End-to-End Lifecycle
المسار الكامل لرحلة البيانات من واجهة المستخدم عبر الشبكة إلى الخادم وقاعدة البيانات والعودة للواجهة.
Service Layer
الطبقة البرمجية المخصصة لتنفيذ قواعد الأعمال والعمليات الحسابية بعيداً عن بروتوكولات الشبكة وقواعد البيانات.

سؤال مقابلات شهير: إزاي بتصمم معمارية تطبيق تجارة إلكترونية يتحمل مليون مستخدم متزامن؟

الإجابة الهندسية المتكاملة:
1. الواجهة و Edge CDN: نشر ملفات الـ Static على Cloudflare CDN مع كاش للمحتوى الثابت.
2. طبقة الخوادم (Stateless Backend): تشغيل حاويات Express في Kubernetes مع Auto-scaling و Load Balancer أمامي.
3. طبقة الكاش والتخفيف (Redis Layer): تخزين بيانات الجلسات والمنتجات الأكثر تصفحاً في Redis Cluster.
4. طبقة قواعد البيانات: استخدام PostgreSQL مع مجمع اتصالات PgBouncer، وقراءة البيانات من Read Replicas وحصر الكتابة في Master DB.
5. العمليات الثقيلة غير المتزامنة: إرسال الإيميلات وتوليد الفواتير عبر Message Queues (BullMQ / RabbitMQ).
