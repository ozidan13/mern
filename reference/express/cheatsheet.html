Express.js 5.2 Architecture Cheatsheet

Core methods, request properties, and middleware signatures at a glance.

Request Object (req)

PropertyDescriptionExample
req.paramsURL route parameters/users/:id → req.params.id
req.queryURL query string key-values/search?q=node → req.query.q
req.bodyParsed JSON payload (via express.json)req.body.email
req.headersIncoming HTTP headers objectreq.headers.authorization

Response Object (res)

MethodDescription
res.status(code)Sets the HTTP status code (chainable)
res.json(obj)Sends JSON response with Content-Type header
res.send(data)Sends plain text or HTML buffer
res.sendStatus(code)Sends status code with its standard text message
