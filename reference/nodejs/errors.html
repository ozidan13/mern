Node.js System Error Code Catalog

Complete diagnostic and resolution playbook for common Node.js runtime exceptions.

EADDRINUSE — Address Already in Use

System Error

Triggered when: A server attempts to bind to a local port or IP address that is already bound by another running process (e.g. an existing background node instance).

السبب: محاولة تشغيل خادم على منفذ (Port) محجوز بالفعل بواسطة عملية أخرى قيد التشغيل في الخلفية.

Error: listen EADDRINUSE: address already in use :::3000

How to Fix in Development · الحل النموذجي

# On Windows (PowerShell):
Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess | Stop-Process

# On Linux/macOS:
lsof -ti :3000 | xargs kill -9

ECONNREFUSED — Connection Refused

Network Error

Triggered when: An outgoing client connection (e.g. database or fetch) could not be established because the target host actively rejected it (server is offline or wrong port).

السبب: محاولة الاتصال بخادم أو قاعدة بيانات مغلقة أو لا تستمع على المنفذ المطلوب.
