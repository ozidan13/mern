React 19.2 Hooks & API Reference

Complete signature reference, dependencies rules, and best practices.

Core Built-in Hooks

Hook SignaturePurposeDependencies?
const [state, setState] = useState(initial) Declares local component memory preserved across renders None
useEffect(setup, dependencies?) Synchronizes component with an external system [] or [dep1, dep2]
useMemo(calculateValue, dependencies) Caches the result of an expensive calculation Required array
useCallback(fn, dependencies) Caches a function definition between re-renders Required array
useRef(initialValue) Holds mutable value or DOM node reference without causing re-renders None
useContext(SomeContext) Subscribes to shared parent Context provider value None

React 19 Modern Additions

FeatureDescription
use(Promise / Context) Reads the value of a Promise or Context conditionally inside render
useActionState(fn, initial) Manages form action states with pending indicators and optimistic results
useOptimistic(state, updateFn) Applies optimistic UI updates immediately while async action runs
