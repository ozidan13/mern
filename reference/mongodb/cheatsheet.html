MongoDB Query & Aggregation Cheatsheet

Core CRUD operators, array updates, and aggregation pipeline stages.

Query Comparison Operators

OperatorMeaningSyntax Example
$eq / $neEqual / Not Equal{ age: { $eq: 25 } }
$gt / $gteGreater Than / Equal{ price: { $gte: 100 } }
$in / $ninIn Array / Not In{ status: { $in: ['A', 'B'] } }

Update Operators

OperatorActionExample
$setSets value of a field{ $set: { verified: true } }
$pushAppends item to array{ $push: { tags: 'react' } }
$incIncrements number{ $inc: { views: 1 } }
